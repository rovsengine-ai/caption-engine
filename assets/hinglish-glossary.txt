# Hinglish glossary
#
# Two kinds of entry:
#
#   <source phrase> => <english phrase>    MAP: Devanagari-written English back to
#                                          its real English spelling
#   <english phrase>                       PROTECT: never let any backend alter it
#
# WHY MAPPINGS ARE NEEDED
# ASR frequently writes English words in Devanagari when the surrounding speech
# is Hindi: "cheat day" comes back as "चीट डे". Phonetic transliteration then
# produces "cheet de" — correct rules, lossy input. Nothing but a mapping can
# recover the English spelling, because चीट could equally be cheet/chit/cheat.
#
# RULE: both sides must have the SAME number of tokens, so each output word keeps
# the timestamp of the word it replaced. The loader rejects mismatches.
#
# This list is deliberately incomplete and is expected to grow with your content.
# Add entries as you hit them; --hinglish-glossary <file> merges your own on top.
